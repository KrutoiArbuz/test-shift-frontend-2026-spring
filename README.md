# Авторизация — Шифт Лаба

Форма авторизации по номеру телефона и OTP-коду.

## Функционал

- Ввод номера телефона с маскированием (только цифры).
- Запрос OTP-кода на введённый номер.
- Ввод и валидация шестизначного кода.
- Обработка ошибок API с отображением в интерфейсе.

## Запуск

Убедитесь, что установлен Node.js (v24+).

**1. Установите зависимости:**

```bash
npm install
```

**2. Создайте `.env` файл:**

```
VITE_API_URL=https://shift-intensive.ru/api
```

**3. Запустите dev-сервер:**

```bash
npm run dev
```

Приложение доступно по адресу: http://localhost:5173
